\section{Introduction}

This project studies the key design choices in SimCLR for visual representation learning. Instead of training a new supervised classifier from labels only, SimCLR first learns an encoder from unlabeled images. Two random views are generated from each image, and the model is trained to make the two views of the same image close while pushing views from different images apart. After pretraining, the encoder is frozen and a simple linear classifier is trained on top of its features. If the linear classifier performs well, the encoder has learned useful
visual representations.

According to our project plan, the main goal is not to build a more complex model, but to understand which SimCLR components matter. The planned components are data augmentation, projection head, batch size, and low-label evaluation.

\section{Method}

\subsection{Baseline SimCLR}

Our baseline uses CIFAR-10 and a ResNet-18 backbone as encoder. During contrastive pretraining, each input image is transformed twice to produce two augmented views. The implementation uses random resized crop, horizontal flip, color jitter, random grayscale, and Gaussian blur. For a batch of $B$ original images, there are $2B$ views. For each anchor view, its positive example is the other view from the same original image, while the other $2B-2$ views are negatives.

The contrastive loss follows the NT-Xent form used by SimCLR:
\[
\ell_{i,j} =
-\log
\frac{\exp(\operatorname{sim}(z_i,z_j)/\tau)}
{\sum_{k=1}^{2B} \mathbf{1}_{k \ne i}
\exp(\operatorname{sim}(z_i,z_k)/\tau)} ,
\]
where $z$ is the normalized output used by the contrastive loss, $\operatorname{sim}$ is cosine similarity, and $\tau$ is the temperature. In our code the temperature is set to 0.07. The model is optimized with Adam and weight decay during pretraining.

\subsection{Projection Head}

The encoder output of ResNet-18 is a 512-dimensional feature vector. With the projection head enabled, this vector is passed through a two-layer MLP:
\[
512 \rightarrow 512 \rightarrow 128.
\]
The contrastive loss is applied to the projected vector. During linear
evaluation, however, the projection head is removed and the frozen
512-dimensional encoder feature is used. Without the projection head, the
contrastive loss is applied directly to the 512-dimensional encoder output. This comparison tests whether the extra nonlinear head helps the encoder learn better features for later classification.

\subsection{Linear Evaluation}

We use linear evaluation as the main metric. The pretrained encoder is frozen, features are extracted for CIFAR-10 train and test images, and a single linear layer is trained for 100 epochs. The classifier uses Adam with learning rate 0.001 and no weight decay. Accuracy on the CIFAR-10 test set is reported. This protocol is useful because it measures representation quality without allowing the encoder to change during evaluation.

The model with the projection head reaches 63.59\% best test accuracy, while the model without the projection head reaches 62.16\%. This is an improvement of 1.43 percentage points. The final accuracy also improves from 61.40\% to 62.84\%, which is a 1.44 percentage point gain. The result supports the SimCLR idea that the projection head can absorb transformations needed by the contrastive objective, while the encoder output keeps more useful information for downstream classification.

The improvement is not extremely large, but it is consistent across best and final accuracy. Also, the model with the projection head reaches its best result later in linear evaluation. This suggests that its frozen features may contain slightly richer information that the linear classifier can use after more training.

\subsection{Batch Size Ablation}

Batch size changes the number of negatives in the contrastive loss. With two views per image, the number of negatives for each anchor is $2B-2$. We compare batch sizes 128, 256, and 512. The projection head is enabled for this ablation, and the same linear evaluation protocol is used for all three runs.

The best result is obtained at batch size 256, with 510 negatives per anchor and 63.59\% best test accuracy. Batch size 128 is slightly lower at 62.54\%. The largest batch size, 512, performs worst with 60.03\% best accuracy. Therefore, the result does not show a simple rule that larger batch size always gives better features.

This is an important observation. A larger batch gives more negative samples, which should make the contrastive task stronger. However, it also changes the optimization setting. With a fixed number of epochs, a larger batch has fewer parameter updates per epoch. It may also need a different learning rate schedule or longer pretraining. In our runs, batch size 256 gives the best balance between having enough negatives and still maintaining stable optimization.

\section{Discussion}

The data augmentation xxxxxx.

The projection head ablation gives a clear result: using the projection head improves the final representation. It agrees with the motivation of SimCLR. The contrastive objective may require invariances that are useful for matching augmented views, but not all of these changes should be forced directly onto the encoder feature used by the downstream task. The projection head gives the model an extra space for optimizing the pretext task.

The batch size ablation gives a more mixed result. The medium batch size is best, while the largest batch is worse. This does not mean negative samples are unimportant. Rather, it shows that batch size is tied to optimization details. If batch size changes, the number of updates, learning rate behavior, memory pressure, and training stability can also change. Therefore, batch size should not be interpreted as only a 'negative sample count' variable.

\section{Future Work}

Future work should run each setting with multiple seeds and report mean and standard deviation. The batch size ablation should also test learning-rate scaling, longer pretraining, and schedules that are matched by number of optimization steps rather than only by epochs. After the low-label experiments are completed, we can compare SimCLR pretraining against direct supervised training under 1\%, 10\%, and 100\% label fractions. It would also be useful to add k-nearest-neighbor evaluation and feature-space visualization as supporting evidence.

\section{Conclusion}

This project studies SimCLR through controlled ablation experiments. For the completed parts, the projection head improves CIFAR-10 linear evaluation accuracy from 62.16\% to 63.59\%, showing that the nonlinear head is useful for learning transferable encoder features. The batch size ablation shows that batch size 256 performs best among 128, 256, and 512. The result suggests that more negatives are helpful only when optimization remains stable. Overall, SimCLR performance depends on both representation design and training details, so ablation studies are necessary for understanding why the method works.
